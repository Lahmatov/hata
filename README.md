# Хата: ежедневный монитор квартир T3 (Большой Лиссабон)

Каждое утро присылает в Telegram дайджест **новых** объявлений и **снижений цены** по критериям:
T3, от 90 м², от 2 санузлов, с гаражом, до 415 000 € (до 430 000 € с пометкой «нужен торг»), рядом с
PaRK International School (вход: Rua das Mil Flores, Alfragide; 38.735766, -9.226091). Время в пути до школы: машина, утро.

Объявления сгруппированы так: 🆕 НОВЫЕ · 📉 СНИЖЕНИЕ ЦЕНЫ · ❓ ПРОВЕРИТЬ ВРУЧНУЮ (не удалось
определить гараж, санузлы или цену). В одном сообщении не больше 15 объявлений, внизу строка
об источниках, которые сегодня не ответили.

## Как это работает

```
адаптеры (Imovirtual, Casa Sapo, Trovit, Idealista API) ──► SQLite (data/hata.sqlite) ──► дедупликация между порталами
      │ вежливый HTTP: свой User-Agent, robots.txt,          │
      │ 6–10 с между запросами к одному сайту, кэш 12 ч,     ▼
      │ блокировка (403/429/captcha) = источник пропущен     фильтр по критериям ──► время до школы
      ▼                                                       (OSRM × коэфф. пробок или Google Routes)
страница объявления (санузлы, гараж, лифт, координаты)        ▼
                                                     описание: факты (код) + плюс/минус (Claude) ──► Telegram
```

- **Факты** (цена, м², €/м², гараж, этаж/лифт, состояние, минуты до школы) собираются кодом,
  поэтому модель не может их «придумать». **Плюс и минус** пишет Claude (`claude-sonnet-4-6`) только
  по извлечённым полям и тексту объявления. Без ключа Anthropic работает простая rule-based замена.
- **Новое** значит, что эту квартиру (с учётом дублей на других порталах) вам ещё не присылали.
  **Снижение цены** значит, что текущая цена ниже той, о которой вы уже знаете.
- **Дубли**: одинаковый адрес (или координаты в пределах ~150 м), площадь и цена отличаются не больше чем на 3%.

## Почтовые рассылки порталов (Idealista, Supercasa, OLX, RE/MAX…)

Сайты, которые мы не читаем напрямую, сами умеют присылать письма о новых объявлениях по сохранённому
поиску. Монитор читает эти письма из отдельного ящика (только чтение) и добавляет объявления в общий
дайджест с дедупликацией и временем до школы.

1. Заведите отдельный Gmail, включите в нём двухэтапную проверку и создайте «Пароль приложения»:
   myaccount.google.com/apppasswords.
2. На каждом портале (с этим e-mail) сохраните поиск с фильтрами (T3, от 90 м², 2+ санузла, гараж,
   до 430 000 €, район) и включите уведомления на почту, лучше «сразу» или «ежедневно».
3. В `.env`: `IMAP_USER=адрес@gmail.com`, `IMAP_PASSWORD=пароль приложения` (16 букв без пробелов).

В письмах обычно нет санузлов и гаража, поэтому такие объявления чаще попадают в «проверить вручную».

## Установка (macOS)

```bash
brew install node            # нужен Node ≥ 22.13 (используется встроенный node:sqlite)
git clone https://github.com/Lahmatov/hata.git && cd hata
npm ci
cp .env.example .env         # впишите TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, ANTHROPIC_API_KEY
npm test                     # тесты адаптеров и логики (Playwright test runner)
```

## Расписание

### Вариант A: GitHub Actions (не зависит от Mac)
1. Сделайте репозиторий приватным: Settings → General → Danger Zone → Change visibility.
2. Settings → Secrets and variables → Actions → New repository secret:
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY` (необязательно: `GOOGLE_MAPS_API_KEY`).
3. Влейте ветку в `main`, потому что расписание GitHub работает только из ветки по умолчанию.
4. Actions → **daily-digest** → Run workflow с аргументом `--test-telegram`, чтобы проверить отправку.

Cron задан в UTC (`35 6` и `35 7`). Скрипт сам проверяет, что в Лиссабоне 7–8 утра, и отправляет
дайджест один раз в день, поэтому переход на летнее и зимнее время ничего не ломает. GitHub может
запускать cron с опозданием на 5–30 минут. Состояние (SQLite) хранится в Actions cache.

**Остановить:** Actions → daily-digest → ⋯ → Disable workflow.

### Вариант B: launchd на Mac
```bash
./scripts/launchd/install.sh                          # ежедневно в 07:45 по времени Mac
sudo pmset repeat wakeorpoweron MTWRFSU 07:40:00      # будить Mac (нужно питание для ноутбука)
launchctl kickstart -k gui/$(id -u)/com.hata.monitor  # запустить сейчас
```
Если Mac спал в 07:45, launchd запустит задачу сразу после пробуждения.
**Остановить:** `./scripts/launchd/uninstall.sh` (и `sudo pmset repeat cancel`).

## Диагностика

| Симптом | Что делать |
|---|---|
| В дайджесте «Источники с ошибками: X (blocked: HTTP 429/403)» | Сайт ограничил доступ. Мы **не обходим** защиту: источник пропускается до следующего дня. Если блокировка постоянная, отключите адаптер в `src/adapters/index.ts` |
| `__NEXT_DATA__ not found` | Сайт поменял вёрстку. Запустите `npm run fixtures:capture && npm test` и поправьте адаптер |
| Нет времени до школы | Проверьте доступ к `router.project-osrm.org` (и `nominatim.openstreetmap.org` для адресов без координат) |
| Время в пути кажется заниженным или завышенным | Подберите `MORNING_TRAFFIC_FACTOR` (по умолчанию 1.5) или добавьте `GOOGLE_MAPS_API_KEY` (Routes API, учитывает пробки) |
| `Telegram API error 400: chat not found` | Сначала напишите боту любое сообщение, потом заново узнайте chat_id через `getUpdates` |
| `Telegram API error 401` | Неверный токен бота |
| Ничего не пришло утром (Actions) | Actions → daily-digest → последний запуск → логи (также артефакт `logs`) |
| Ничего не пришло утром (Mac) | `tail -50 logs/launchd.out.log`, `launchctl print gui/$(id -u)/com.hata.monitor` |
| Хочу начать с чистого листа | Удалите `data/hata.sqlite` (в Actions: Actions → Caches → удалить `hata-state-*`) |

## Настройка критериев

`src/config.ts`: бюджет, санузлы, районы (`areas`), предельное время в пути (`hardCommuteMin`, по
умолчанию 35 мин; дольше 20 мин помечается минусом), минимальная площадь (`minAreaM2`, 90 м²), коэффициент пробок.

## Правила, которые соблюдает код

Только публичные страницы, без логина. Понятный User-Agent со ссылкой на репозиторий, проверка
robots.txt, не больше одного запроса в 6–10 секунд на сайт, кэш. При 403/429/captcha источник
пропускается, никаких прокси, решения капчи, подмены отпечатков и stealth-плагинов.
