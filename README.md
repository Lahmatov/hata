# Хата: ежедневный монитор квартир T3 (Большой Лиссабон)

Каждое утро присылает в Telegram дайджест **новых** объявлений и **снижений цены** по критериям:
T3, от 90 м², от 2 санузлов, с гаражом, до 415 000 € (до 430 000 € с пометкой «нужен торг»), рядом с
PaRK International School (вход: Rua das Mil Flores, Alfragide; 38.735766, -9.226091). Время в пути до школы: машина, утро.

Объявления сгруппированы так: 🆕 НОВЫЕ · 📉 СНИЖЕНИЕ ЦЕНЫ · ❓ ПРОВЕРИТЬ ВРУЧНУЮ (не удалось
определить гараж, санузлы или цену). Каждая квартира отдельным постом с фото, в конце строка
об источниках, которые сегодня не ответили.

## Как это работает

```
адаптеры (Imovirtual, Casa Sapo, Trovit, Idealista API) ──► SQLite (data/hata.sqlite) ──► дедупликация между порталами
      │ вежливый HTTP: свой User-Agent, robots.txt,          │
      │ 6–10 с между запросами к одному сайту, кэш 12 ч,     ▼
      │ блокировка (403/429/captcha) = источник пропущен     фильтр по критериям ──► время до школы
      ▼                                                       (OSRM × коэфф. пробок или Google Routes)
страница объявления (санузлы, гараж, лифт, координаты)        ▼
                                                     описание: факты (код) + плюс/минус (Claude) ──► Telegram
```

- **Факты** (цена, м², €/м², гараж, этаж/лифт, состояние, минуты до школы) собираются кодом,
  поэтому модель не может их «придумать». **Плюс и минус** пишет Claude (`claude-sonnet-4-6`) только
  по извлечённым полям и тексту объявления. Без ключа Anthropic работает простая rule-based замена.
- **Новое** значит, что эту квартиру (с учётом дублей на других порталах) вам ещё не присылали.
  **Снижение цены** значит, что текущая цена ниже той, о которой вы уже знаете.
- **Дубли**: одинаковый адрес (или координаты в пределах ~150 м), площадь и цена отличаются не больше чем на 3%.

## Почтовые рассылки порталов (Idealista, Supercasa, OLX, RE/MAX…)

Сайты, которые мы не читаем напрямую, сами умеют присылать письма о новых объявлениях по сохранённому
поиску. Монитор читает эти письма из отдельного ящика (только чтение) и добавляет объявления в общий
дайджест с дедупликацией и временем до школы.

1. В Gmail включите двухэтапную проверку и создайте «Пароль приложения»: myaccount.google.com/apppasswords.
2. На каждом портале сохраните поиск с фильтрами (T3+, от 90 м², 2+ санузла, гараж, до 430 000 €, район)
   и включите уведомления на почту, лучше «сразу» или «ежедневно».
3. Создайте в Gmail ярлык `hata` и фильтр: «От» = `idealista.pt OR idealista.com OR supercasa.pt OR
   imovirtual.com OR casa.sapo.pt OR remax.pt OR era.pt OR century21.pt OR trovit.pt OR zome.pt OR
   kwportugal.pt OR custojusto.pt`, действия «Пропустить входящие» и «Применить ярлык: hata». Письма будут
   лежать только в этой папке, монитор читает именно её (`IMAP_FOLDER`, по умолчанию `hata`).
4. Секреты (или `.env`): `IMAP_USER=адрес@gmail.com`, `IMAP_PASSWORD=пароль приложения` (16 букв без пробелов).

Проверено на настоящих письмах Idealista (английский интерфейс) и Supercasa (русский интерфейс).
В письмах обычно нет санузлов и гаража, поэтому такие объявления чаще попадают в «проверить вручную».

## Установка (macOS)

```bash
brew install node            # нужен Node ≥ 22.13 (используется встроенный node:sqlite)
git clone https://github.com/Lahmatov/hata.git && cd hata
npm ci
cp .env.example .env         # впишите TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, ANTHROPIC_API_KEY
npm test                     # тесты адаптеров и логики (Playwright test runner)
```

## Расписание

### Вариант A: GitHub Actions (основной, не зависит от Mac)
1. Сделайте репозиторий приватным: Settings → General → Danger Zone → Change visibility.
2. Settings → Secrets and variables → Actions → New repository secret:
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY` (необязательно: `GOOGLE_MAPS_API_KEY`).
3. Влейте ветку в `main`, потому что расписание GitHub работает только из ветки по умолчанию.
4. Actions → **daily-digest** → Run workflow с аргументом `--test-telegram`, чтобы проверить отправку.

Три дайджеста в день: утренний (с 07:00 по Лиссабону), дневной (с 13:00) и вечерний (с 19:00). Утренний
приходит всегда, дневной и вечерний только если есть новое. GitHub запускает cron с опозданием (бывает на
часы) или пропускает, поэтому срабатывание стоит каждый час: первый запуск в слоте делает дайджест, остальные
выходят за секунды. Переход на летнее и зимнее время ничего не ломает. Состояние (SQLite) хранится в Actions
cache.

С GitHub (IP дата-центра) Casa Sapo и Trovit не отвечают, поэтому там они не опрашиваются. Работают
Imovirtual, официальный API Idealista (с ключом) и почтовые рассылки (IMAP). Секреты для них:
`IDEALISTA_API_KEY`, `IDEALISTA_API_SECRET`, `IMAP_USER`, `IMAP_PASSWORD`.

**Прислать прямо сейчас:** Actions → daily-digest → Run workflow (аргумент по умолчанию `--force`).

**Кнопки 👍/👎** под каждой квартирой мгновенно обрабатывает бот на Cloudflare (`worker/`); в базу монитора
нажатия копирует каждый дайджест и задача `telegram-buttons` раз в 3 часа (без воркера она же опрашивает Telegram): 👎 скрывает квартиру навсегда (для обоих
получателей) и удаляет её посты из чата, 👍 добавляет в «Избранное». Без своего сервера бот отвечает не мгновенно: кнопка «крутится», пока не придёт очередная проверка. Избранное приходит по воскресеньям утром, а в любой момент его
можно запросить кнопкой «⭐ Избранное» внизу чата или командой /fav.
«Проверить вручную» показываются все сразу (ограничить можно переменной `MAX_MANUAL_ITEMS`). В карточке также: 🔥 «выгодно» (цена за м² заметно ниже средней по
району среди T3 от 90 м²), 💶 история цены и ссылка «🗺 маршрут до школы».
**Остановить:** Actions → daily-digest → ⋯ → Disable workflow.

### Проверки на GitHub
- `ci`: на каждый пуш в рабочую ветку и на PR только типы и тесты (~30 с); новый пуш отменяет старую проверку.
- `dry-run`: полный пробный прогон, только вручную (Actions → dry-run → Run workflow). По умолчанию без догрузки фото
  и не больше 20 страниц объявлений с сайта (несколько минут); `max_detail = 0` снимает лимит. Долгие прогоны —
  это паузы 5–10 с между запросами к сайтам (правило проекта), а не железо раннера.

### Мгновенные кнопки (Cloudflare, бесплатно)
Без своего сервера бот видит нажатия только при запусках на GitHub, поэтому кнопка «крутится». Маленький
обработчик на Cloudflare Workers (`worker/`) отвечает сразу: 👍 отмечает, 👎 удаляет пост у обоих,
«⭐ Избранное» присылает список за секунды. Монитор передаёт ему список отправленных квартир после
каждой рассылки и забирает нажатия перед каждой.

1. Зарегистрируйтесь на dash.cloudflare.com (Free).
2. Account ID: Workers & Pages → справа «Account ID» (или в адресе страницы после `dash.cloudflare.com/`).
3. API-токен: My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers** → Use template →
   Account Resources: ваш аккаунт → Zone Resources: All zones → Continue → Create Token.
4. Секреты GitHub: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`.
5. Actions → **bot-worker** → Run workflow. Он создаст хранилище, выложит обработчик и подключит бота.

### Свайпы (мини-приложение в Telegram)
Кнопка меню «🏠 Свайпы» слева от поля ввода (или /app) открывает все отправленные квартиры карточками,
как в Tinder: фото листаются нажатием (слева назад, справа вперёд), карточку тянут вправо (нравится,
то же что 👍), вверх (🌟 суперлайк) или влево (нет, то же что 👎: пост пропадает из чата у обоих).
Суперлайки хранятся отдельным списком: кнопка «🌟 Суперлайки» внизу чата или /super (под постами
тоже есть кнопка 🌟); по воскресеньям утром приходят оба списка. ↩ возвращает последнюю
карточку. Сначала идут подходящие квартиры, потом «проверить вручную», ближние к школе первыми.
Страница и API живут в том же Cloudflare Worker (`worker/app.ts`), доступ только у получателей из
`TELEGRAM_CHAT_ID` (проверяется подпись Telegram). Все фото объявления монитор собирает сам; у
объявлений, прочитанных раньше, фото дочитываются постепенно, до 150 страниц за запуск (`PHOTO_BACKFILL`), или все разом: daily-digest с аргументом `--force --photo-backfill=700` (~1,5 часа).

### Избранное, рейтинг и таблица
У каждой квартиры есть рейтинг из 100 баллов (`src/score.ts`): цена 25 (полный балл на 60 тыс. ниже
бюджета, ноль на 430 тыс.), дорога до школы 25 (10 мин и меньше полный, 35 мин ноль), площадь 15
(90 м² 3 балла, от 130 м² полный), цена за м² против медианы района 15 (на 20% дешевле полный, на 20%
дороже ноль), состояние 10, удобства 10 (3+ санузла, лифт, балкон или терраса, кладовка, кондиционер,
бассейн или закрытый комплекс, спальня с санузлом; удобства ищутся в тексте объявления). Неизвестное
получает средний балл. Разбивка видна на карточке.

В «Свайпах» три вкладки: «🏠 Новые», «⭐ Избранное» (второй раунд по тому, что лайкнул хоть один из
вас, лучшие по баллам сначала, видно, кто лайкнул; вправо оставить, вверх «точно смотреть», влево
убрать из своего избранного, у второго человека его лайк остаётся) и «🏆 Рейтинг» (список по баллам).
Кнопка «📊 Таблица» в чате, /export или кнопка во вкладке «Рейтинг» присылают файл Excel со всем
избранным: оценки каждого из вас, баллы и их разбивка, район, адрес, цена и её история, €/м² и
отличие от района, площадь, спальни, санузлы, гараж, этаж, лифт, состояние, год постройки,
энергокласс, удобства, дорога, сколько дней в продаже, что проверить, ссылки на объявление, маршрут и
другие порталы, плюс пустые колонки «Позвонили», «Просмотр», «Впечатление», «Заметки».

С `GOOGLE_MAPS_API_KEY` время до школы считается с учётом пробок на 08:15 буднего дня (Routes API,
тариф Pro). При добавлении или удалении ключа время пересчитывается у всех квартир, не больше
`GOOGLE_MAX_CALLS` (по умолчанию 50) запросов за запуск, сначала для ещё не отправленных квартир (в Google
Cloud стоит лимит 150 в день: бесплатно 5000 в месяц); остальные ждут следующего запуска и до
этого не рассылаются.

### Совпадения, новости и данные по избранному
- 💞 Когда квартира нравится обоим, бот пишет обоим. По избранному раз за запуск приходят новости: подешевела,
  не видна на сайтах 3 дня (снята), снова в продаже.
- В «⭐ Избранное» у карточки общий статус, заметка и время просмотра (кнопка «в Google Календарь»); во вкладке
  «🏆 Рейтинг» карта избранного и сравнение 2–4 квартир.
- 🚶 «Погулять» (на карте и в карточке) показывает Street View вокруг квартиры. С карты сначала открывается её
  карточка, так что, вернувшись из Google Maps, вы на ней. Чтобы Street View открывался прямо в приложении (с
  кнопкой «← К карточке» и стрелкой «назад» Telegram), нужен отдельный ключ: Google Cloud → APIs & Services →
  включить **Maps Embed API** (бесплатный, без лимита) → Credentials → Create API key → Restrict key:
  Application restrictions: Websites, адрес бота из Actions → bot-worker (строка `url=`), например
  `https://hata-bot.<ваш-поддомен>.workers.dev/*`; API restrictions: только Maps Embed API. Затем добавить его в секреты репозитория как `MAPS_EMBED_KEY` и перезапустить Actions → bot-worker. Ключ
  виден странице, поэтому не используйте ключ от Routes (`GOOGLE_MAPS_API_KEY`).
- 💶 Расходы при покупке (`src/costs.ts`): IMT по таблицам 2026 года с IMT Jovem (покупателям до 35 лет:
  до 330 539 € IMT и гербовый сбор 0, выше только с превышения; `IMT_JOVEM=0` выключает), гербовый сбор на
  кредит 0,6%, Casa Pronta 700 €, платёж по ипотеке (`MORTGAGE_SHARE` 0.8, `MORTGAGE_RATE` 0.032,
  `MORTGAGE_YEARS` 30) и кондоминиум, если он указан в объявлении. Это оценка, без ставки для нерезидентов
  и банковских комиссий.
- 📊 Цены сделок INE (показатель 0012234, медиана €/м² за 12 месяцев, по районам Большого Лиссабона,
  раз в неделю, CC-BY): насколько цена за м² выше или ниже сделок в районе.
- 📍 Что рядом (OpenStreetMap, Overpass API): станция, супермаркет, аптека, парк, площадка, по прямой; только
  для избранного с точным адресом, до 20 квартир за запуск (`NEARBY_MAX`), результат хранится.
- 🌊 Подтопление (карты APA по директиве 2007/60/EC): в зоне затопления или в 500 м от зоны значимого риска.
  Карты есть только для зон риска, поэтому «нет на картах» не гарантия. До 20 за запуск (`FLOOD_MAX`).
- ✈️ Низкие самолёты (OpenSky Network, открытый API без регистрации): workflow `planes` раз в день по часу (утром
  или вечером через день) снимает небо над Большим Лиссабоном каждые 20 с (~180 из ~400 бесплатных запросов) и хранит самолёты
  ниже 1200 м 14 дней. Для каждой квартиры с точным адресом: сколько раз в час трек проходил ниже 1 км не дальше
  1 км от дома и самый низкий пролёт; показывается после 3 часов наблюдений. Готовых карт шума нет (карта EEA
  пуста для Лиссабона, открытые данные мэрии закрыты защитой от ботов, у ANA только PDF).

### Вариант B: launchd на Mac
```bash
./scripts/launchd/install.sh                          # 07:45, 13:45 и 19:45 по времени Mac
sudo pmset repeat wakeorpoweron MTWRFSU 07:40:00      # будить Mac (нужно питание для ноутбука)
launchctl kickstart -k gui/$(id -u)/com.hata.monitor  # запустить сейчас
```
Если Mac спал в 07:45, launchd запустит задачу сразу после пробуждения.
**Остановить:** `./scripts/launchd/uninstall.sh` (и `sudo pmset repeat cancel`).

## Диагностика

| Симптом | Что делать |
|---|---|
| В дайджесте «Источники с ошибками: X (blocked: HTTP 429/403)» | Сайт ограничил доступ. Мы **не обходим** защиту: источник пропускается до следующего дня. Если блокировка постоянная, отключите адаптер в `src/adapters/index.ts` |
| `__NEXT_DATA__ not found` | Сайт поменял вёрстку. Запустите `npm run fixtures:capture && npm test` и поправьте адаптер |
| Нет времени до школы | Проверьте доступ к `router.project-osrm.org` (и `nominatim.openstreetmap.org` для адресов без координат) |
| Время в пути кажется заниженным или завышенным | Подберите `MORNING_TRAFFIC_FACTOR` (по умолчанию 1.5) или добавьте `GOOGLE_MAPS_API_KEY` (Routes API, учитывает пробки) |
| `Telegram API error 400: chat not found` | Сначала напишите боту любое сообщение, потом заново узнайте chat_id через `getUpdates` |
| `Telegram API error 401` | Неверный токен бота |
| Ничего не пришло утром (Actions) | Actions → daily-digest → последний запуск → логи (также артефакт `logs`) |
| Ничего не пришло утром (Mac) | `tail -50 logs/launchd.out.log`, `launchctl print gui/$(id -u)/com.hata.monitor` |
| Хочу начать с чистого листа | Удалите `data/hata.sqlite` (в Actions: Actions → Caches → удалить `hata-state-*`) |

## Настройка критериев

`src/config.ts`: бюджет, санузлы, районы (`areas`), предельное время в пути (`hardCommuteMin`, по
умолчанию 35 мин; дольше 20 мин помечается минусом), минимальная площадь (`minAreaM2`, 90 м²), коэффициент пробок.

## Правила, которые соблюдает код

Только публичные страницы, без логина. Понятный User-Agent со ссылкой на репозиторий, проверка
robots.txt, не больше одного запроса в 6–10 секунд на сайт, кэш. При 403/429/captcha источник
пропускается, никаких прокси, решения капчи, подмены отпечатков и stealth-плагинов.
